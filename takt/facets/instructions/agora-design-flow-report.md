# 完了を報告する

人が、実装が設計に沿っていることと、どんな ADR を作ったか（設計とその背景）を確かめられるように、完了報告を作ってください。ファイルを編集しないでください。

## 集めるもの

- Report Directory の設計レポート（最新のもの）と検証レポート。再設計があった場合は、各回の設計レポートと検証レポート
- `docs/adr/` の ADR。作った・更新した ADR の番号・題・ステータスは、ADR のファイルを読んで確かめる
- 最終の検証レポートが確認した、ADR と `agora-design` の項目への適合

レポートの内容は、設計レポートや検証レポートの記載だけで済ませず、ADR のファイルと現在のコードで確かめた事実で書く。確かめられなかったものは「未確認」と書く。

次の status を 1 つだけ選択してください。
- `reported`: 報告を作った。

# 修正の確認の範囲

修正の確認は、裁定が修正対象とした問題の受け入れ条件を満たしたかを確かめる。新しい観点のレビューはしない。

## 原則

| 原則 | 基準 |
|------|------|
| 受け入れ条件で確かめる | 裁定（review-resolution.md）の「修正する問題」の受け入れ条件を、1 つずつ満たしたかで判定する |
| 修正が壊したものは見る | 修正の差分が、受け入れ条件の外で既存の振る舞いやテストを壊していないかは確かめる |
| 新しい指摘を足さない | 受け入れ条件と関係しない改善点や、前からある問題を、確認の不合格の理由にしない。気づいたら「今回の範囲外」として記録だけする |

## 判定基準

| 基準 | 判定 |
|------|------|
| 受け入れ条件と関係しない指摘で不合格にしている | REJECT |
| 受け入れ条件を確かめずに合格にしている | REJECT |

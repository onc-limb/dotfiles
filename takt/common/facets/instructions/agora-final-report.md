**summary.md の末尾に、指示書の「最終レポート」を置いてください。**

TAKT は PR の本文に、作業の結果として決まった一文しか書きません。この run の summary.md が、run の後に PR の本文へ書き写されます。人が PR で読むのはここだけです。

- 指示書（order.md）に「最終レポートに書くこと」（または同じ役割の節）があれば、summary.md の最後に `## 最終レポート` の節を足し、その項目を 1 つずつ `###` の見出しにして埋める。順番も指示書のとおりにする。
- 材料は、計画・テストのレポート・実装のレポート・coder-decisions・各レビュー・裁定のレポートと、現在のコード。自分で確かめたことと、レポートの記述に頼ったことを分けて書く。
- 決まった書式の節（結果・要件充足・合意仕様からの逸脱・前段 finding・未解消の問題）は、そのまま残す。最終レポートで、それらの節を書き直さない。
- 項目に書くことが無いときは「なし」と書く。確かめていないことは、確かめていないと書く。
- ローカルの絶対パスを書かない。ファイルはリポジトリの直下からの相対パスで書く。
- 指示書に該当する節が無ければ、この節は足さない。
